# TESL-Manager

Desktop-приложение оператора (внутреннее имя в коде — "Uploder") для публикации
релизов сборки Skyrim SE + MO2 на WebDAV-депо, которое потребляет лаунчер
[TESL](https://github.com/scp-oss/TESL).

## Вкладки (актуальные, подключены в `main_window.py`)

- **🏷️ Релизы** (`release_tab.py` + `release_manager.py`) — компонентная публикация:
  три компонента (Skyrim / MO2p / MO2ext), у каждого свой локальный путь и список
  исключений. Публикует `depot.json` + `manifests/<version>.json` + плоские файлы
  под `files/<Компонент>/<путь>` на WebDAV. Активация версии по каналам
  (stable/beta/dev), откат, дозаливка недокачанного релиза, удаление версии из
  индекса (без удаления файлов).
- **🗂️ Файлы сервера** (`server_files_tab.py`) — просмотр дерева WebDAV (PROPFIND
  Depth: infinity).
- **📦 Статик-папки** (`static_folders_tab.py`) — для папок, которые не версионируются
  (патчер, крэш-логи) — строит `manifest.json` по уже загруженным вручную файлам.
- **⚙️ Настройки** — WebDAV-подключение (URL/логин/пароль/путь), хранится в
  `%APPDATA%/Uploder/config.json` на машине оператора.

## ⚠️ Дормантный/исторический chunk-based депо-протокол

`depot_sync_manager.py`/`chunk_manager.py`/`depot_tab.py`/`depot_confirm_dialog.py`/
`confirm_dialog.py`/`launcher_client.py`/`threads.py` реализуют ВТОРОЙ,
content-addressed протокол (`chunks/<xx>/<hash>`, `versions/<key>.json`,
`depot.json`). В текущем срезе кода `depot_tab.py` не подключена к
`MainWindow.tabs` — но **это не мёртвый код**: реальный продакшен-сервер физически
хранит депо именно в этом формате (см. `CLAUDE.md`) — там же сейчас единственная
оставшаяся копия одной из сборок после утраты локальных исходников. См.
CLAUDE.md → "Восстановление сборки из чанков" — это сейчас приоритет №1 для
этого репозитория, ПЕРЕД любой новой функциональностью.

## 🔴 Восстановление сборки из чанков

`depot_sync_manager/recover_from_chunks.py` — отдельный CLI-скрипт (Python
3.9+, только `requests`, без Qt) для сборки утраченной сборки обратно из
`chunks/`+`versions/` на WebDAV. Схема манифеста подтверждена реальными
данными сервера (гибрид: chunk-хранилище + компонентный `Skyrim`/`MO2p`/
`MO2ext` манифест версии, см. CLAUDE.md). Запускать на машине, где будет
жить восстановленная сборка (обычно — ПК оператора, не эта песочница —
здесь нет доступа к продакшен-учётным данным). Сначала ВСЕГДА `--dry-run`
(отчёт + проверка, что все нужные чанки ещё есть на сервере), потом реальная
закачка. Полные примеры команд — в докстринге самого файла.

Каждый запуск (и `--dry-run`, и реальный) автоматически заносит разобранный
манифест версии и итоги в локальный индекс (`db.py`, SQLite,
`%APPDATA%/Uploder/uploder.db`) — см. следующий раздел; отключается
`--no-db`.

## Локальный индекс релизов/чанков (`db.py`, `ingest_local.py`)

Операторский SQLite-индекс того, что видели на сервере (`%APPDATA%/Uploder/
uploder.db`) — **не** то, что читает TESL, только для запросов на стороне
оператора. Таблицы: `releases`/`components`/`files`/`chunks` (нормализованный
слепок манифестов версий) и `recovery_runs` (журнал запусков
`recover_from_chunks.py`). Заполняется автоматически при `recover_from_chunks.py`,
или вручную из уже скачанных `depot.json`/`versions/<key>.json` через
`depot_sync_manager/ingest_local.py` (без сети — если файлы уже где-то
лежат, самый быстрый способ получить их в БД для запросов; можно занести
только `depot.json`, без большого файла версии — агрегаты запишутся сразу,
полный sync дополнит позже). `release_manager.py` (публикация из GUI) пока
в эту БД не пишет, см. CLAUDE.md.

## `manifest.db` — то, что реально читает лаунчер (`build_manifest_db.py`)

**Это ДРУГОЙ файл, не `uploder.db` выше.** `depot_sync_manager/build_manifest_db.py`
— "одноразовый конвертор" (прямой запрос пользователя): берёт уже скачанные
`depot.json` + `versions/<key>.json` и пишет компактный `manifest.db`
(SQLite, одна версия на файл, только `files`+`chunks`+`meta` — без сырого
JSON внутри, не раздувает файл). Этот `.db` заливается оператором на
WebDAV **рядом с JSON-манифестом версии, тот же путь, расширение `.db`
вместо `.json`** — TESL сам его находит и, если он есть, устанавливает
сборку напрямую из `chunks/`, минуя необходимость пересобирать и
перезаливать весь билд под старым плоским протоколом. См. TESL::CLAUDE.md
"Chunk-протокол на стороне лаунчера" за клиентскую половину.

## Запуск из исходников

```
pip install -r requirements.txt
cd depot_sync_manager
python main.py
```

Никаких секретов в коде нет — WebDAV-логин/пароль вводятся в UI (вкладка
"⚙️ Настройки") и сохраняются локально в `%APPDATA%/Uploder/config.json`.

## Сборка .exe

```
cd depot_sync_manager
"build pyw.bat"
```
